# これいる？いらない？

洋服、食器、本、家具など、なんでも写真をまとめて送って、遠くにいる家族に「いる / 迷う / いらない」を選んでもらうためのサイトです。

- **送る人**: 部屋をつくる → 写真をまとめて選ぶ → 出てきたリンクを LINE などで送る
- **選ぶ人**: リンクを開く → 写真を1枚ずつ見て、ボタンを押すだけ（ひとことコメントも書けます）
- 結果は送る人の画面にすぐ出ます。「いる」だけに絞り込めるので、そのまま荷造りに使えます
- 写真はあとから足しても、相手の画面に自動で出てきます
- アカウント登録は不要です。リンクを知っている人だけが見られます

## セットアップ（最初に1回だけ・約10分）

写真と判定結果の保存に Firebase（Google の無料サービス）を使います。

### 1. Firebase を用意する

1. <https://console.firebase.google.com/> を開いて「プロジェクトを作成」（名前は何でも OK、Google アナリティクスはオフで OK）
2. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
   - ロケーションは `asia-northeast1 (東京)` がおすすめ
   - 「本番環境モード」で作成
3. Firestore の「ルール」タブを開き、このリポジトリの [`firestore.rules`](firestore.rules) の中身を全部貼り付けて「公開」
4. 歯車アイコン →「プロジェクトの設定」→ 下の方の「マイアプリ」で `</>`（ウェブ）を押してアプリを登録
5. 表示される `firebaseConfig = { ... }` の中身を、[`config.js`](config.js) に貼り付けて保存

> Firebase の `apiKey` は公開されても問題ない値です（アクセスの制限は `firestore.rules` で行っています）。

### 2. GitHub Pages で公開する

1. このリポジトリの Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

## 使い方

1. 公開したサイトを開いて「新しい部屋をつくる」
2. 「＋ 写真を選ぶ」から写真をまとめて選ぶ（スマホならカメラロールから複数選択できます）
3. 「LINEで送る」かリンクをコピーして相手に送る
4. 相手が選ぶと、上の「相手の返事」の数字が増えていきます。「いる」を押すと、ほしいものだけが並びます

送る人用の画面のアドレスはブックマークしておいてください（同じスマホなら、トップページの「前につくった部屋」からも戻れます）。

## メモ

- 写真はアップロード前にスマホの中で縮小しています（1枚あたり数百KB）。Firebase の無料枠（1GB）で数千枚は入ります
- 写真ごとに「メモ」（例: 食器セット 6枚 未使用）を付けられます
- 不要になった写真は「消す」で削除できます
